# `frontend-mockup` — aesthetic-directions menu

Pick 5 from this menu (or invent matching ones). Each pick must differ from the others in at least 3 of: typography, color hierarchy, spatial composition, motion, atmosphere.

| # | Direction | Signature |
| --- | --- | --- |
| 1 | Brutalist / raw | Mono fonts, hard borders, exposed grid, dense info, high contrast |
| 2 | Refined minimal | Generous whitespace, single accent color, subtle shadows, restrained type |
| 3 | Editorial / typography-led | Serif display + sans body, magazine-style spacing, asymmetric grid |
| 4 | Maximalist / dense | Multiple fonts, layered colors, decorative borders, bold patterns |
| 5 | Retro-futuristic / geometric | Geometric shapes, vintage palette, pixel/grid motifs |
| 6 | Organic / natural | Soft shapes, hand-drawn elements, earthy palette, fluid type |
| 7 | Luxury / refined | Thin weights, deep neutrals, gold/silver accents, generous spacing |
| 8 | Playful / toy-like | Rounded shapes, bright colors, bouncy motion, friendly type |
| 9 | Industrial / utilitarian | Rectangular, mono palette, condensed type, function-first |
| 10 | Soft / pastel | Pastel palette, soft shadows, friendly serifs, gentle motion |
| 11 | Dark mode by default | Deep base, neon/electric accents, glow effects |
| 12 | Glassmorphism / gradient | Translucent panels, gradient accents, blurred backgrounds |

## Anti-default

- NEVER use Inter, Roboto, Arial as the body font.
- NEVER use the purple-gradient-on-white "AI slop" combo.
- NEVER converge on the same fonts across samples.

## Diversity test

If you can describe two of your samples in the same sentence ("both are minimal"), one of them needs to change.

# Diagramkit Integration

## Default Tooling

Prefer project-local diagramkit when available:

```bash
npx diagramkit render <source-file>
```

Use a global install only when the project does not already include diagramkit:

```bash
diagramkit render <source-file>
```

## Warmup

Browser-backed engines need Chromium once per environment:

```bash
npx diagramkit warmup
```

## Output Model

By default diagramkit renders output into a `.diagramkit/` subfolder next to the source file. Many projects override this with `sameFolder: true` in `diagramkit.config.json5`, which places rendered assets as direct siblings of the source.

Default layout (no config or `sameFolder: false`):

```text
docs/architecture/diagrams/auth-flow.mermaid
docs/architecture/diagrams/.diagramkit/auth-flow-light.svg
docs/architecture/diagrams/.diagramkit/auth-flow-dark.svg
```

Same-folder layout (`sameFolder: true`):

```text
docs/architecture/diagrams/auth-flow.mermaid
docs/architecture/diagrams/auth-flow-light.svg
docs/architecture/diagrams/auth-flow-dark.svg
```

Always check `diagramkit.config.json5` (if it exists) to determine the actual output path, then update the markdown embed to match.

## Recommended Commands

Render SVG variants for markdown docs:

```bash
npx diagramkit render docs/architecture/diagrams/auth-flow.mermaid --format svg --theme both
```

Render PNG when the target system needs raster output:

```bash
npx diagramkit render docs/architecture/diagrams/auth-flow.mermaid --format png --theme light
```

## Engine Coverage

Diagramkit supports:

- Mermaid: `.mermaid`, `.mmd`, `.mmdc`
- Excalidraw: `.excalidraw`
- Draw.io: `.drawio`, `.drawio.xml`, `.dio`
- Graphviz: `.dot`, `.gv`, `.graphviz`

## Markdown Rule

Update the markdown after rendering so it points at the actual SVG output path generated by diagramkit, not just the source file location.

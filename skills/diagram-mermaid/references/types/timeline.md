# Timeline

**Directive:** `timeline`

**Syntax:**

```
timeline
    title Timeline Title
    section Period 1
        Event 1 : Description
        Event 2 : Description
    section Period 2
        Event 3 : Description
```

**Example:**

```
%% Diagram: Product Roadmap
%% Type: timeline
timeline
    title 2025 Product Roadmap
    section Q1
        Auth System : OAuth2 integration
                    : SSO support
        API v2 : REST to GraphQL migration
    section Q2
        Mobile App : iOS launch
                   : Android launch
        Analytics : Real-time dashboards
    section Q3
        Marketplace : Partner integrations
                    : Payment processing
        Performance : CDN rollout
                    : Edge caching
    section Q4
        Enterprise : RBAC
                   : Audit logging
                   : SOC 2 compliance
```

# Pie Chart

**Directive:** `pie`

**Syntax:**

```
pie title Chart Title
    "Segment 1" : 40
    "Segment 2" : 30
    "Segment 3" : 20
    "Segment 4" : 10
```

**Example:**

```
%% Diagram: Error Distribution
%% Type: pie
pie title Production Errors by Category
    "Timeout" : 35
    "Auth Failure" : 25
    "Validation" : 20
    "Database" : 12
    "External API" : 8
```

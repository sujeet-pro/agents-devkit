# `docs-write` — per-phase validator

Logged to `.temp/task-<slug>/validation/docs-write.md`.

## Phase 0 — pre-execution

- [ ] `.temp/task-<slug>/` exists and is gitignored.
- [ ] User's prompt captured verbatim in `prompt.txt`.
- [ ] Doc type classified (`readme` / `adr` / `runbook` / `migration` /
      `freeform`) with confidence label.
- [ ] Repo resolved via `repos.md` or inferred with `inferred` tag.

## Phase 1 — preflight

- [ ] `bin/adk-info --check` returned 0.
- [ ] `~/.config/adk/docs.md` parses and `audience_default` has a value
      (or defaulted to `engineer`).
- [ ] Target canonical path resolved for `--fix` (existence recorded).
- [ ] If target path exists and is tracked by git, `git log -1 --format=%an %ae`
      captured for the overwrite-asks-once gate.

## Phase 2 — evidence map

- [ ] `sources.md` exists.
- [ ] At least 5 claims with file:line citations (for README / runbook /
      migration guide) OR at least 3 for ADR / free-form.
- [ ] Any `TODO: verify` is listed in the "Unverified" section of
      `sources.md`, not embedded silently in the draft.

## Phase 3 — draft

- [ ] `draft.md` exists.
- [ ] Every claim in the draft maps to an entry in `sources.md`.
- [ ] `<!-- validation -->` block is present with: `claims`, `audience`,
      `template`, `external-quotes`, `todos-verify`.
- [ ] `external-quotes: 0` OR every quote is ≤15 words (enforced by
      counting words between `>` lines in the draft).
- [ ] No "generated by" / "written by AI" footer anywhere.
- [ ] Every code fence has a language tag when the code is in a known
      language (so GitHub renders it).
- [ ] Heading depth ≤4 (don't go past `####`).

## Phase 4 — pre-promotion (under `--fix`)

- [ ] `todos-verify: 0` in the draft's validation block.
- [ ] Draft length is within 30-80% of the target-template reference
      length (guardrail against "one-paragraph README").
- [ ] If the target path exists: backup copied to
      `.temp/task-<slug>/backup/<basename>`, overwrite confirmed.
- [ ] `git add <path>` succeeded.
- [ ] No write happened outside `.temp/task-<slug>/` other than the
      target canonical path.
- [ ] No `git commit` / `git push` was called.

## On any check failure

- Log the failure with the remediation.
- Block promotion.
- After 3 same-kind failures in a session, stop and surface to the user.

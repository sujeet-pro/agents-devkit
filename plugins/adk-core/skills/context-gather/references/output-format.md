## Sections

- **Sources** — table; one row per URL.
- **Summary per source** — one section per URL; includes summary, excerpts, action items.
- **Cross-references** — explicit links between sources.
- **Action items detected (consolidated)** — flat list across all sources.
- **Open questions** — what's still missing.

## Rules

- Every quoted excerpt must be ≤15 words.
- Every source must have a status (OK / ACCESS DENIED / 404 / NOT READABLE).
- Quote attribution: `alice (source-type)` so the reader can find the origin.
- Never include attachment URLs or file contents from attachments without explicit opt-in.

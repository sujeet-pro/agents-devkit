# Skill Reference

Every page in this section is generated from the live `skills/<name>/SKILL.md` file. Each skill is fully self-contained — one folder with `SKILL.md` plus a flat `references/` directory carrying its own copy of persona, workflow, output format, constitution, and any other supporting material. There is no `_shared/`, no auto-propagation, no cross-skill file references.

Each skill works alone when copied out of this repo. The references shipped alongside `SKILL.md` cover everything the skill needs: there are no shared helper skills to install separately, no `_shared/` directory, no cross-skill includes.

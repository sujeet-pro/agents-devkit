# Skills

One reference page per skill in `skills/<name>/SKILL.md`. Pages are auto-generated by `@adk:prj-update-docs` (a.k.a. `adk-prj-update-docs`); do not hand-edit — change the SKILL.md instead and re-run the generator.

## How to use

- Pick a skill from the sidebar.
- Each page leads with the artifact's purpose, then `Usage`, then the full SKILL.md body.
- Cross-links between skills follow the dual-form convention: `@adk:<name>` (a.k.a. `adk-<name>`).

## Categories

- **Top router** — `adk`
- **Category routers** — `audit`, `build`, `docs`, `frontend`, `plan`, `publish`, `review`, `visualize`
- **Task skills** — every other skill, scoped to one well-defined responsibility.

## Source

`skills/<name>/SKILL.md` — see `AGENTS.md` for the canonical skill anatomy.

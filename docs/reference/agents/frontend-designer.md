# frontend-designer

Creates distinctive, production-grade frontend and design-system directions with strong accessibility, responsiveness, and implementation detail.

## Role

Generates HTML preview variations with different design approaches. Focuses on accessibility (WCAG), responsive design, and practical implementation within the target framework.

## Allowed Tools

Read, Write, Bash, Glob, Grep, WebSearch, WebFetch

## Used By

- `design` — generates 5 parallel design variations

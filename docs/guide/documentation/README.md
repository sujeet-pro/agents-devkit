# Documentation

Create, update, review, template, and publish engineering documentation.

> **Quick start:** `/adk-write-docs` is the simplest entrypoint for this category.

## Included Skills

| Skill | Purpose | Reference |
| --- | --- | --- |
| `/adk-write-docs` | Write, update, improve, or publish engineering documentation using named templates or a custom template URL or file. Use when documentation is the main deliverable | [Details](../../reference/skill-adk-write-docs.md) |
| `/adk-review-docs` | Review documentation for accuracy, completeness, clarity, style, and example quality. Use when documentation review itself is the main task | [Details](../../reference/skill-adk-review-docs.md) |

## Example Invocations

```text
/adk-write-docs <prompt-text>
/adk-review-docs <url>
```

## How To Use This Guide

Start with the skill whose primary job matches the outcome you want. Use the linked reference page for the exact flag surface, workflow contract, and validation expectations.

# Research & Planning

Research topics, close ambiguity, create implementation plans, and write specifications.

> **Quick start:** `/adk-brainstorm` is the simplest entrypoint for this category.

## Included Skills

| Skill | Purpose | Reference |
| --- | --- | --- |
| `/adk-brainstorm` | Run iterative brainstorming to narrow options, question assumptions, choose blast radius, and route into the right implementation or documentation skill. Use when a task needs design closure before work begins | [Details](../../reference/skill-adk-brainstorm.md) |
| `/adk-plan` | Create an executable implementation plan with scoped files, risks, and validation checkpoints. Use when a request needs a reviewable plan before code or docs changes | [Details](../../reference/skill-adk-plan.md) |
| `/adk-research` | Run structured technical research with repo evidence, primary sources, and explicit uncertainty. Use when a task depends on external facts or upstream behavior | [Details](../../reference/skill-adk-research.md) |
| `/adk-spec` | Write product requirements, technical specifications, API specs, or feature acceptance criteria. Use when defining what to build before planning how | [Details](../../reference/skill-adk-spec.md) |

## Example Invocations

```text
/adk-brainstorm <prompt-text>
/adk-plan <prompt-text>
/adk-research <question>
/adk-spec <prompt-text>
```

## How To Use This Guide

Start with the skill whose primary job matches the outcome you want. Use the linked reference page for the exact flag surface, workflow contract, and validation expectations.

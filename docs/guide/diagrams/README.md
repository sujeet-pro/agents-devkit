# Visuals & Design

Create diagrams, charts, and interface design direction with the right artifact type.

> **Quick start:** `/adk-diagram` is the simplest entrypoint for this category.

## Included Skills

| Skill | Purpose | Reference |
| --- | --- | --- |
| `/adk-diagram` | Create or update markdown docs with editable diagram source files across Mermaid, Excalidraw, Draw.io, and Graphviz, rendered via diagramkit. Use when a document needs a maintained in-repo diagram | [Details](../../reference/skill-adk-diagram.md) |
| `/adk-chart` | Create data charts from source data or documented metrics with reusable data files and rendered assets. Use when the deliverable is a chart rather than a system diagram | [Details](../../reference/skill-adk-chart.md) |
| `/adk-design` | Design, audit, or polish interfaces with clear UX goals, accessibility constraints, and implementation realism. Use when UI or UX quality is the main job | [Details](../../reference/skill-adk-design.md) |

## Example Invocations

```text
/adk-diagram <diagram-request>
/adk-chart <chart-request>
/adk-design <prompt-text>
```

## How To Use This Guide

Start with the skill whose primary job matches the outcome you want. Use the linked reference page for the exact flag surface, workflow contract, and validation expectations.

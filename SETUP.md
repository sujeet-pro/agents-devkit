# claude-devkit Auto-Setup Instructions

> **For Claude Code**: Read this file and follow the steps below to install claude-devkit for the user.
> Execute each phase sequentially. Wait for user input where indicated.

---

## Phase 1: Install Everything (Recommended)

Start by installing the full devkit. This is the fastest path — recommend this to the user first.

## Phase 2: Register the Marketplace

```bash
/plugin marketplace add sujeet-pro/claude-devkit
```

---

## Phase 3: Install Full Devkit

Install everything — skills, agents, and guidelines:

```bash
/plugin install devkit-full@claude-devkit
```

Tell the user: **Full devkit installed.** All skills, agents, and guidelines are now available globally.

> **Note**: If the user asks to install only specific plugins instead of the full devkit, inform them that selective installation has caveats (missing dependencies reduce quality, no MCP config, no context instructions). Recommend `devkit-full` and proceed. If they insist on selective install, see the README.md "Selective Plugin Install" section for the list of available plugins and their caveats.

---

## Phase 4: Configure MCP Servers

Ask the user:

> **Which external services do you use? I'll configure the MCP servers for them.**
>
> Available integrations:
> 1. **Confluence** — Document operations (read/write Confluence pages)
> 2. **Bitbucket** — PR reviews and repo operations on Bitbucket
> 3. **Google Drive** — Read/write Google Docs, Sheets, Slides
>
> Note: **Slack**, **Gmail**, and **Google Calendar** are Claude.ai built-in integrations — no setup needed here. Connect them via Claude Desktop → Settings → Integrations.

For each service the user selects, follow the subsection below.

### 4a. Environment Variable Setup

For each selected service, check if the required environment variables are already set.

**Confluence** requires:
- `CONFLUENCE_URL` — e.g. `https://yoursite.atlassian.net/wiki`
- `CONFLUENCE_USERNAME` — Atlassian account email
- `CONFLUENCE_API_TOKEN` — Atlassian API token

**Bitbucket** requires:
- `BITBUCKET_TOKEN` — Bitbucket API Token (Repository or Workspace Access Token)

**Google Drive** requires:
- `GOOGLE_MCP_CLIENT_ID` — Google OAuth Client ID (from Google Cloud Console)
- `GOOGLE_MCP_CLIENT_SECRET` — Google OAuth Client Secret
- `GOOGLE_DRIVE_OAUTH_CREDENTIALS` — Path to credentials file (auto-generated by setup script)

Run this to check which vars are already set:

```bash
source ~/.zshenv 2>/dev/null || true
for var in CONFLUENCE_URL CONFLUENCE_USERNAME CONFLUENCE_API_TOKEN BITBUCKET_TOKEN GOOGLE_MCP_CLIENT_ID GOOGLE_MCP_CLIENT_SECRET GOOGLE_DRIVE_OAUTH_CREDENTIALS; do
  val="${(P)var:-}"
  if [ -n "$val" ]; then
    len=${#val}
    if [ $len -gt 12 ]; then
      masked="${val:0:4}...${val: -4}"
    elif [ $len -gt 4 ]; then
      masked="${val:0:2}..."
    else
      masked="***"
    fi
    printf "  ✓ %-35s %s\n" "$var" "$masked"
  else
    printf "  ✗ %-35s NOT SET\n" "$var"
  fi
done
```

### 4b. Missing Variables

For any required variable that is **NOT SET**, tell the user:

> The following environment variables need to be added to `~/.zshenv`:
>
> ```bash
> export VARIABLE_NAME="your-value-here"
> ```
>
> Please update `~/.zshenv` with the missing values and let me know when you're done.

**WAIT** for the user to confirm they have updated `~/.zshenv`.

### 4c. Reload and Verify

Once the user confirms the update, reload the environment and verify:

```bash
source ~/.zshenv
```

Then re-run the check from 4a to confirm all required variables are now set. If any are still missing, ask the user to fix them and repeat.

### 4d. Configure MCP in ~/.claude.json

Once all required variables are confirmed, configure each selected MCP server by reading `~/.claude.json`, merging the server config, and writing it back.

**Confluence:**
```bash
source ~/.zshenv && jq --arg url "$CONFLUENCE_URL" --arg user "$CONFLUENCE_USERNAME" --arg token "$CONFLUENCE_API_TOKEN" \
  '.mcpServers["atlassian-confluence"] = {"type":"stdio","command":"uvx","args":["mcp-atlassian"],"env":{"CONFLUENCE_URL":$url,"CONFLUENCE_USERNAME":$user,"CONFLUENCE_API_TOKEN":$token}}' \
  ~/.claude.json > /tmp/claude-json-tmp && mv /tmp/claude-json-tmp ~/.claude.json
```

**Bitbucket:**
```bash
source ~/.zshenv && jq --arg token "$BITBUCKET_TOKEN" \
  '.mcpServers["bitbucket"] = {"type":"stdio","command":"npx","args":["-y","bitbucket-mcp@latest"],"env":{"BITBUCKET_TOKEN":$token}}' \
  ~/.claude.json > /tmp/claude-json-tmp && mv /tmp/claude-json-tmp ~/.claude.json
```

**Google Drive:**
```bash
### Google Drive setup (two steps):

**Step 1: Generate credentials file** (if not already done):
```bash
source ~/.zshenv && zsh ~/.claude/scripts/setup-google-drive.zsh
```
This generates the OAuth credentials file from your `GOOGLE_MCP_CLIENT_ID` and `GOOGLE_MCP_CLIENT_SECRET`, then opens a browser for OAuth consent.

**Step 2: Configure MCP server**:
```bash
source ~/.zshenv && jq --arg creds "$GOOGLE_DRIVE_OAUTH_CREDENTIALS" \
  '.mcpServers["google-drive"] = {"type":"stdio","command":"npx","args":["-y","@piotr-agier/google-drive-mcp"],"env":{"GOOGLE_DRIVE_OAUTH_CREDENTIALS":$creds}}' \
  ~/.claude.json > /tmp/claude-json-tmp && mv /tmp/claude-json-tmp ~/.claude.json
```

## Phase 5: Verify Installation

After all configuration is done:

```bash
echo "Verifying installation..."
echo ""
echo "Installed MCP servers:"
jq -r '.mcpServers | keys[]' ~/.claude.json 2>/dev/null || echo "  (none)"
echo ""
echo "Try running these commands to verify skills are loaded:"
echo "  /validate-mcp    — test MCP server connectivity"
echo "  /pr-review --help"
echo "  /research --help"
```

Tell the user: **Setup complete! You can now use the devkit skills in any project.**
